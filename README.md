# RevAutoHub

**RevAutoHub** is a web-based vehicle breakdown assistance and automotive service platform designed to connect drivers with nearby mechanics and provide emergency roadside assistance.

## Features

* User registration and login
* Emergency breakdown assistance
* Mechanic registration and discovery
* Location-based mechanic services
* Automotive service and assistance requests
* M-Pesa payment integration

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Payments:** Safaricom Daraja API (M-Pesa STK Push)
* **API Testing:** Postman

## Architecture

The application follows a layered backend architecture using Spring Boot, with separate **Controller, Service, Repository, Entity, and DTO** layers.

## Purpose

RevAutoHub was developed as a practical project to apply my knowledge of **Java, Spring Boot, REST APIs, databases, and third-party API integration** while building a real-world automotive service solution.
